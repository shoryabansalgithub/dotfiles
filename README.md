# dotfiles

Terminal setup: WezTerm as the terminal, herdr inside it.

| File | Goes to |
| --- | --- |
| `wezterm/wezterm.lua` | `~/.config/wezterm/wezterm.lua` (Windows: `%USERPROFILE%\.wezterm.lua`) |
| `herdr/config.toml` | `~/.config/herdr/config.toml` |

WezTerm uses the Hack Nerd Font and the rose-pine-moon color scheme. F11 (or Alt+Enter) toggles full screen; on Windows the native title bar is kept so maximize is always there.
